How to read it

  • A badge such as 6 in counts the other domains that import the node at least 3 times.
  • Arrow width never changes. The number carries the weight.
  • A lib/X.ts file counts with lib/X/ when both exist.

Method

The counter reads every .ts and .tsx file under lib/, tests excluded (*.test.*). It counts static import and export … from statements plus dynamic import("…") calls whose path starts with @/lib/ or is relative. A path resolves to X.ts, X.tsx or X/index.ts. A domain is the first folder under lib/. A top-level file lib/X.ts joins domain X when lib/X/ exists (for example foods.ts and meals.ts); the other top-level files form "top-level files". The counts match the Archify map on every edge it showed. The script is not part of the repo.
