# Capture auto-resolve gate (W125, T3)

**Ruling (the owner, through the coordinator, 2026-10-17):** take the conservative option. A
photo, label or typed capture picks its catalog match without asking only at high confidence;
otherwise the confirm sheet shows the choices and the user picks.

## The value

| Setting | Value | Meaning |
|---|---|---|
| `minScore` | 0.95 | The top match's search score (0–1) must be at least this. |
| `minMargin` | 0.30 | The top match must lead the second by at least this. |
| hits | ≥ 2 | A lone hit never auto-resolves: there is nothing to compare it with. |

These equal the search eval's current thresholds (`lib/search/thresholds.ts`, generated by
`scripts/search-eval.ts` at ≥ 98 % auto-resolve precision). A capture must clear both the eval's
pair and this floor, so a later eval run that loosens its pair does not loosen capture.

## Changing it

Edit `CAPTURE_AUTO_RESOLVE` in `lib/capture/auto-resolve-gate.ts`. Raise either number to ask
more often; lower it to ask less (it cannot go below the eval's own pair). The test
`tests/capture/auto-resolve-gate.test.ts` pins the boundary cases.
