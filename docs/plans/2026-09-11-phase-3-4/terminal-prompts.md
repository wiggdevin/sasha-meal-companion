# Phases 3 + 4 — terminal prompts (wave 3)

**Start condition:** `main` includes PR #27 and the pre-lane setup PR (`chore/p3-4-pre-lane`: zxing-wasm, `lib/capture/types.ts`,
`lib/capture/flags.ts`, `lib/policy/constraints.ts`). The same text lives in `prompts/<lane>.txt` so a terminal can be opened
with the prompt pre-sent on the house model:

```bash
cd ~/projects/clients/Sasha/meal-companion && git checkout main && git pull --ff-only
for L in K:p3-barcode L:p3-recipes-favorites-water M:p4-capture-server N:p4-capture-client O:p1-search-recall; do n=${L%%:*}; b=${L##*:}; git worktree add ../meal-companion-$n -b feat/$b main; done
for n in K L M N O; do (cd ../meal-companion-$n && pnpm install --frozen-lockfile && cp ../meal-companion/.env.local .env.local); done
for n in K L M N O; do scripts/lane-terminal.sh $n docs/plans/2026-09-11-phase-3-4/prompts/$n.txt; done
```

`scripts/lane-terminal.sh` opens a Terminal window in the worktree, runs `claude --model claude-fable-5-1` (effort high, the house
driver) and sends the prompt as the first message. Without the prompt-file argument it opens idle and you paste the block below.
Two-terminal variant: K+L in one (run K's prompt, then L's after it lands), M+N in another, O in a third.
