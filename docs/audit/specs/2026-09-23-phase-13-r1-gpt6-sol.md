**DO NOT SHIP.** The proposed privacy boundary and allergen safety rule are not enforceable as written. The decision to keep DeepSeek out of runtime is sound, but it does not resolve the Jev paths already carrying user data.

1. **[BLOCK] The route lane violates its own D0 rule.** The spec permits user text in Jev’s `route` lane, then relies on a medical vocabulary filter ([spec:64](/Users/zero-suminc./projects/clients/Sasha/mc-p13/docs/specs/phase-13-model-lanes-food-safety.md:64), [spec:71](/Users/zero-suminc./projects/clients/Sasha/mc-p13/docs/specs/phase-13-model-lanes-food-safety.md:71)). Phase 10 already rejected a vocabulary filter for this reason ([phase-10:458](/Users/zero-suminc./projects/clients/Sasha/mc-p13/docs/specs/phase-10-conversational-onboarding.md:458)). **Fix:** send no raw user message to Jev without a cleared D1/D2 lane; use local routing or Gemini behind its gate.
