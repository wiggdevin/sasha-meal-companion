1. [BLOCK] **The memory commit RPC can bypass the account boundary.** The proposed `security definer` function accepts `p_user_id`, but the spec defines no `EXECUTE` restriction or internal caller check ([spec:453](/Users/zero-suminc./projects/clients/Sasha/meal-companion/docs/specs/phase-11-conversations-memory.md:453), [spec:717](/Users/zero-suminc./projects/clients/Sasha/meal-companion/docs/specs/phase-11-conversations-memory.md:717)). Postgres grants new functions to `PUBLIC` by default; the existing privileged RPC pattern explicitly revokes that grant ([migration:71](/Users/zero-suminc./projects/clients/Sasha/meal-companion/supabase/migrations/20261023091000_target_revision_transactions.sql:71), [migration:85](/Users/zero-suminc./projects/clients/Sasha/meal-companion/supabase/migrations/20261023091000_target_revision_transactions.sql:85)). A direct RPC caller could supply another account’s ID, bypassing the route and `coach_memories` RLS. Grant execution only to `service_role`, or verify `auth.uid()` inside the function; test direct anon and authenticated RPC calls.

2. [BLOCK] **The specified transaction cannot run the judges in the current stack.** `commit_memory()` is supposed to hold a Postgres row lock while running the medical and dedupe Jev checks ([spec:455](/Users/zero-suminc./projects/clients/Sasha/meal-companion/docs/specs/phase-11-conversations-memory.md:455), [spec:467](/Users/zero-suminc./projects/clients/Sasha/meal-companion/docs/specs/phase-11-conversations-memory.md:467)). Jev is called by JavaScript through `systemOne()` and `fetch` ([typesafe.ts:284](/Users/zero-suminc./projects/clients/Sasha/meal-companion/lib/ai/typesafe.ts:284)); the spec defines no database implementation for that call. It also promises a transactional, same-lock “Forget everything” operation while naming only the commit function ([spec:477](/Users/zero-suminc./projects/clients/Sasha/meal-companion/docs/specs/phase-11-conversations-memory.md:477)). Define executable database entry points for both operations, with the judges outside SQL and a revalidation/retry protocol that preserves the stated race guarantees.

3. [BLOCK] **Clients can alter the forget fence directly.** `coach_memory_state` is assigned standard pattern-1 RLS ([spec:453](/Users/zero-suminc./projects/clients/Sasha/meal-companion/docs/specs/phase-11-conversations-memory.md:453), [spec:659](/Users/zero-suminc./projects/clients/Sasha/meal-companion/docs/specs/phase-11-conversations-memory.md:659)), which grants authenticated owners insert, update, and delete ([rls.sql:5](/Users/zero-suminc./projects/clients/Sasha/meal-companion/supabase/migrations/20260911000500_rls.sql:5)). A direct PostgREST update can clear or move `forgotten_at`, allowing a stale save past the fence. Make state mutations service-managed and test direct JWT writes. This reintroduces the tampering issue acknowledged in the spec’s Round 2 resolution ([spec:930](/Users/zero-suminc./projects/clients/Sasha/meal-companion/docs/specs/phase-11-conversations-memory.md:930)).
