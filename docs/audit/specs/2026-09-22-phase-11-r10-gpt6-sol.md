Verdict: DO NOT SHIP — 3 BLOCK, 3 FIX, 0 NIT

1. [BLOCK] **Direct database writes can undo a soft delete or bypass the 30-day purge.** The spec protects pinned threads but adds no guard for ordinary chat tombstones ([spec:358](/Users/zero-suminc./projects/clients/Sasha/meal-companion/docs/specs/phase-11-conversations-memory.md:358)). Authenticated owners still have direct `UPDATE` and `DELETE` on `coach_threads` ([RLS:17](/Users/zero-suminc./projects/clients/Sasha/meal-companion/supabase/migrations/20260911000500_rls.sql:17)). They can set `deleted_at` back to null, making a deleted chat searchable and writable again, or hard-delete it before the purge. Enforce an irreversible tombstone transition and reserve hard deletion for the purge job; test both direct PostgREST attempts.

2. [BLOCK] **Search pagination uses two incompatible orders.** The search RPC is specified to order by `ts_rank` ([spec:636](/Users/zero-suminc./projects/clients/Sasha/meal-companion/docs/specs/phase-11-conversations-memory.md:636)), while its cursor contains only `last_message_at` and `id` ([spec:349](/Users/zero-suminc./projects/clients/Sasha/meal-companion/docs/specs/phase-11-conversations-memory.md:349)). A high-ranked old hit at the end of page one can cause newer, lower-ranked hits to be skipped. Define one total order and put every ordering key in the cursor. Return each matching thread once, even when several messages match.

3. [BLOCK] **A paged list cannot prove that a cached thread was deleted.** The UI fetches one page and loads older pages on scroll ([spec:351](/Users/zero-suminc./projects/clients/Sasha/meal-companion/docs/specs/phase-11-conversations-memory.md:351)), yet the second-device rule evicts every cached ID absent from “the server’s list” on the next fetch ([spec:425](/Users/zero-suminc./projects/clients/Sasha/meal-companion/docs/specs/phase-11-conversations-memory.md:425)). An active thread on page two is absent from page one. Specify a tombstone feed, per-ID validation, or complete enumeration before eviction; also clear an already open transcript when deletion is confirmed. Test a cached, active thread beyond page one alongside a deleted thread.

4. [FIX] **The list cursor has no value for empty threads.** `last_message_at` is nullable ([migration:11](/Users/zero-suminc./projects/clients/Sasha/meal-companion/supabase/migrations/20261001000000_phase7_coach.sql:11)), and the existing create route can make an empty thread without setting it ([route:37](/Users/zero-suminc./projects/clients/Sasha/meal-companion/app/api/coach/threads/route.ts:37)). The proposed backfill reads message timestamps, so it cannot fill those rows ([spec:328](/Users/zero-suminc./projects/clients/Sasha/meal-companion/docs/specs/phase-11-conversations-memory.md:328)). Use a non-null ordering value such as `coalesce(last_message_at, created_at)` consistently in the query, cursor, and displayed time, or explicitly exclude empty threads.

5. [FIX] **The paged response lacks a defined migration for its existing consumer.** The spec adds `nextCursor` to `GET /api/coach/threads` ([spec:351](/Users/zero-suminc./projects/clients/Sasha/meal-companion/docs/specs/phase-11-conversations-memory.md:351)), but `listThreads()` currently returns an array ([client:258](/Users/zero-suminc./projects/clients/Sasha/meal-companion/lib/coach-client.ts:258)) and coach resume calls `.find()` on it ([screen:61](/Users/zero-suminc./projects/clients/Sasha/meal-companion/app/coach/CoachScreen.tsx:61)). Define the response shape and update both the list UI and resume consumer, with a reload test after pagination is enabled.

6. [FIX] **The specified cache eviction function does not typecheck against its prerequisite.** The spec gives `removeCache(h: AccountHandle | null, ...)` a direct call to `cacheKey(h, ...)` ([spec:417](/Users/zero-suminc./projects/clients/Sasha/meal-companion/docs/specs/phase-11-conversations-memory.md:417)), while PR #248’s `cacheKey` requires a non-null `AccountHandle` ([client:85](/Users/zero-suminc./projects/clients/Sasha/meal-companion/.claude/worktrees/agent-af9e42fc3664b612b/lib/coach-client.ts:85)). Define the null case and test deletion completing after an account switch.
