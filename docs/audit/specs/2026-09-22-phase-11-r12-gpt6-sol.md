[FIX] **The resume query can select an empty chat.** When the last message is deleted, the new trigger sets `last_message_at` to the thread’s `created_at` ([spec:344](/Users/zero-suminc./projects/clients/Sasha/meal-companion/docs/specs/phase-11-conversations-memory.md:344)). Query for an existing message instead, or keep the stored timestamp null for empty threads and use `coalesce` only for list ordering. Test a recently emptied chat alongside an older chat that still has messages.
