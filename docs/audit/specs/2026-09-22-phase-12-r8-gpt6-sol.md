1. [BLOCK] **Retired actions can still run from local state and old cards.** The spec filters new turns and POST replay but keeps historical actions for display (`docs/specs/phase-12-coach-tools.md:100-118`). `CoachShell` restores cached actions (`components/coach/CoachShell.tsx:110-115`); a restored pending action becomes retryable, and Retry makes it pending again (`lib/coach/chat-state.ts:150-158,174-178`). `applyCoachAction` still dispatches retired kinds (`lib/coach/apply-client.ts:87-103`). Historical food-idea blocks also retain a slot and can create `set_slot_meal` on tap (`app/api/coach/threads/[id]/route.ts:41-48`; `components/CoachComposedCard.tsx:45-69`). Add an apply-time client rejection for all seven retired kinds, remove their retry path, and suppress “Put it in” on historical and cached cards. Test an upgrade with a failed cached action and an old food-idea block.

2. [BLOCK] **Research can return to later model turns through history and recall.** The spec excludes only the research *assistant* message (`docs/specs/phase-12-coach-tools.md:250-254`). The current history reader loads both roles without a provenance filter (`lib/server/coach-threads.ts:120-130`), so the research user message remains available. Phase 11’s `recall_conversations` also searches `coach_messages.content` and returns snippets (`docs/specs/phase-11-conversations-memory.md:567-582`), including a stored research answer. Mark the whole research turn and exclude both messages from later model history, summaries, and recall results. Test a later ordinary turn that explicitly asks to recall the research exchange.

3. [BLOCK] **The 999 limit still permits a silently partial progress CSV.** The proposed check bounds entries, but `streamProgress` requests `(limit + 1) × NUTRIENT_CODES.length` raw rows (`lib/server/export.ts:333-345`). There are 20 nutrient codes (`lib/nutrients/codes.ts:7-11`). With the specified 1,000-row PostgREST cap, a 92-day range can return only its first 50 fully populated days; `truncated` stays false because it compares the returned count with a 20,000-row cap (`lib/server/export.ts:265-283`). The file is then accepted as complete under `docs/specs/phase-12-coach-tools.md:201-212`. Page the raw totals within the hosted cap or use a bounded grouped query, and test a range with more than 1,000 `daily_totals` rows.

4. [FIX] **Meal exports can lose food names while retaining item rows.** For a permitted 999-entry page, `namesFor` makes one `food_refs` read for every distinct item ref (`lib/server/export.ts:135-140,183-196`). More than 1,000 distinct refs hit the same PostgREST cap; later items are emitted as `"(unknown food)"` without an error. Chunk the name and catalog lookups within the cap, and test a complete page with more than 1,000 distinct food refs.
